# Gold Rate Calculator

A responsive gold price calculator for Pakistan, ready for GitHub Pages.

## Features
- Gold rate in PKR per tola and per gram
- 24K, 22K and 21K karat selection
- Live international gold rate conversion to PKR
- Live USD/PKR exchange rate
- Wastage: No / Standard Masha per Tola / Manual grams
- Standard wastage defaults to 2 Masha per Tola
- Making amount entered directly in PKR
- Responsive desktop/mobile design

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `gold-rate-calculator`.
2. Upload the contents of this package.
3. Keep `index.html` directly in the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/ (root)**, then click **Save**.
7. Your site will be published at `https://YOUR-USERNAME.github.io/gold-rate-calculator/`.

## Note
The live-rate buttons use public browser-side APIs. Their availability, CORS policy, rate limits, and data source can change independently of the calculator.
