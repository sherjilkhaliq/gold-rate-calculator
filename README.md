# Gold Rate Calculator

A static gold jewellery calculator for Pakistan.

## Features

- Live XAU/USD gold price
- Live/latest USD → PKR exchange rate
- Automatic 24K PKR per tola calculation
- 24K / 22K / 21K gold rates per gram
- Weight, wastage and making-charge calculation
- Wastage in Masha/Tola or manual grams
- Responsive design
- Runs entirely as a static GitHub Pages website

## GitHub Pages

Upload `index.html`, the `css` folder and the `js` folder to the root of your repository.

Then enable:

**Repository → Settings → Pages → Deploy from a branch → main → / (root)**

Your site will then be available at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Market data

The calculator retrieves XAU/USD and USD/PKR from public web APIs. Rates are indicative and should be verified against the actual market/dealer rate before a transaction.
